# simpleudp — basic UDP send/receive over veth

Minimal end-to-end example: send UDP packets generated by the simpleudp
plugin across a veth pair and verify that the receiver netns's XDP counter
(`rx_queue_N_xdp_packets`) matches the number of packets sent.

## Topology

See the diagram in the [examples README](../README.md#how-it-works): two
netns (`xdperf-tx` / `xdperf-rx`) connected by a veth pair
(`xdp-tx` 192.168.100.1/24 <-> `xdp-rx` 192.168.100.2/24).

## Run

```bash
# At the repository root, beforehand:
make build

sudo ./setup.sh
sudo ./test.sh
sudo ./teardown.sh
```

## Parameters (environment variables)

| Variable | Default | Description |
|----------|---------|-------------|
| `COUNT` | `10k` | Number of packets to send |
| `PPS` | `10k` | Send rate |
| `PAYLOAD_SIZE` | `256` | UDP payload size |
| `DST_PORT` | `10001` | Destination port |
| `PLUGIN` | `simpleudp.tinygo` | Plugin to use |
| `PASS_THRESHOLD` | `100` | Receive rate (%) required to PASS |
